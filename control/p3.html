Controller settings

PWM is limited to 0–100%. The setpoint steps from 0 to 40 speed units.

Predict, then check

Keep the gains fixed. What happens to the width of each PWM step when the sampling time increases from 0.05 s to 0.50 s?

Check your prediction

Each step lasts ten times longer. The controller waits longer before correcting an error, so the output can overshoot or oscillate. Try both settings.

To test windup, set Kp = 4, Ki = 10 and Ts = 0.05 s. Compare the peak speed with anti-windup on and off.

Plant model

τ dy/dt = K u − y. Between samples, PWM stays constant while Euler integration advances the motor model.

Defaults are the homework reference plant (K = 1, τ = 1 s). Use your team’s measured motor values when available. K is speed units per PWM percentage point.
